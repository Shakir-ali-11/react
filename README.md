# Cosmic Illusions

A responsive, space-inspired gallery website built with React and CSS.

## Live Website

https://shakirproject.vercel.app/

## Features

- Semantic header, navigation, main content, and footer
- Home, Illusions, and Contact sections
- Responsive layout for mobile screens
- Three gallery images with alt text
- Reusable Header and Footer components

## Run Locally

npm install
npm run dev

## Production Build

npm run build

## Deployment

Hosted on Vercel and connected to the GitHub repository.
Production branch: main.
